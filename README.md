# Planificador + Asignador de Inspectores

App web (un solo archivo `index.html`) para cargar puntos geolocalizados, verlos por comuna en un mapa y asignarlos a inspectores por cercanía.

- **Planificador:** carga puntos e inspectores, ve las dos pestañas, descarga Excel/KML por inspector.
- **Asignador:** asigna puntos a inspectores y carga licencias.
- Datos en tiempo real con Firebase (Authentication + Firestore). Ingreso con contraseña por perfil.

Sitio: https://derlismarce.github.io/Planificador-asignador/
